The Problem: October 2025 Reality Check

🚨 Portugal's €500 Million Question

On October 24, 2025, the Portuguese government authorized €500M in capital injections to 44 public hospitals to cover "arrears" (overdue liabilities >90 days).

What Traditional Models Say

  • Z-scores >5.5 = "Financially Viable"
  • High equity/liability ratios
  • Positive working capital
  • ✓ All hospitals "healthy"

What Reality Shows

  • €1.5-2B in overdue supplier debt
  • 150-250 day payment delays
  • 60-70% subsidy dependent
  • ✗ Continuous bailout cycle
The Paradox: How can hospitals be simultaneously "financially viable" (according to Z-scores) and require €500M bailouts? Traditional corporate finance models are not just imprecise—they are fundamentally wrong for public entities.

Theoretical Innovation Framework

1. Stakeholder-Distributed Financial Distress

Traditional Distress (Private Firm):
Firm → Bankruptcy Risk
↓
Stakeholders Lose Simultaneously
Public Hospital Distress (New Model):
Hospital → State Absorbs/Redistributes
↓
Sequential Losses:
1. Suppliers (delays)
2. Staff (overwork)
3. Patients (quality↓)
4. Taxpayers (subsidies)
5. Future (debt)

2. Modified Capital Structure Theory

Pecking Order in Public Hospitals

Standard: Internal funds → Debt → Equity

Public Hospital: Government subsidies → Retained earnings → Supplier credit (delays) → Debt NEVER

Trade-Off Prediction:
Tax shield benefit = 0 (no taxes)
+ Distress cost = ∞ (threatens mission)
= Optimal leverage = 0 ✓

3. "Ratchet-Plus-Rescue" Soft Budget Constraints

  • Each bailout creates new spending baseline (ratchet)
  • Expected future rescues weaken discipline (moral hazard)
  • Suppliers and staff anticipate bailouts, adjust behavior

New Measure: Public Hospital Financial Sustainability Index

PHFSI = Weighted Average of 5 Components (Range: 0-1)
Replaces bankruptcy-based models with mission-focused sustainability

Component 1: Operational Self-Sufficiency Ratio (20%)

OSSR = Operating Revenue (excl. subsidies) / Operating Expenses

Measures: Can hospital operate without government money?

Component 2: Stakeholder Pressure Index (20%)

SPI = [Payment Days/90] + [Overdue/Total Liabilities] + Staff Turnover + Complaints

Measures: Who is bearing the financial stress?

Component 3: Liquidity Realization Rate (20%)

LRR = Cash Collections(t) / Accrued Revenue(t-1)

Measures: Can hospital actually collect its receivables?

Component 4: True Leverage Ratio (20%)

TLR = (Liabilities + NPV Future Subsidies) / Operating Retained Earnings

Measures: Real leverage including implicit government debt

Component 5: Clinical Quality Maintenance Index (20%)

CQMI = [Safety + Access + Outcomes] / Regional Benchmarks

Measures: Is mission being fulfilled despite financial stress?

Research Design: Multi-Method Approach

1
Phase 1: Develop & Validate PHFSI

Build index from SNS data (2017-2022) → Test if it predicts 2023-2025 capital injections → ROC curve analysis

2
Phase 2: Panel Regression Analysis

Fixed Effects + Arellano-Bond GMM → Test governance effects → Control for endogeneity → Hospital + Year fixed effects

3
Phase 3: Quasi-Experimental DiD

Natural Experiment: 2024 ULS Integration Reform → Staggered rollout = Treatment variation → Test parallel trends → Estimate causal effect

4
Phase 4: Governance Mechanisms

Survey (n=40-50 hospitals) + Archival data → Board composition, incentives, political factors → Mediation analysis

Key Methodological Advances:
  • Panel data solves cross-sectional limitations
  • DiD provides causal identification (not just correlation)
  • Government intervention = observable outcome (validatable)
  • Multi-method triangulation strengthens inferences

Policy Implications for Portugal

🚀 Immediate Actions (0-12 months)

1. Adopt PHFSI Dashboard

  • Replace Z-scores with PHFSI
  • Quarterly public reporting
  • Early warning thresholds
  • Integrate into transparency portal

2. Accelerate Payments

  • Reduce reimbursement lag to <45 days
  • Expected: 50% reduction in supplier delays
  • PHFSI improvement: +0.15

3. Transparent Subsidy Accounting

  • Separate subsidies from "equity"
  • Disclose subsidy dependence ratio
  • 5-year reduction targets

4. Protect Small Suppliers

  • Priority payment for invoices <€10k
  • Interest on late payments (enforced)
  • Supplier financing program

🎯 Medium-Term Reforms (1-3 years)

Governance Mandate

  • Board Requirements: Min. 2 members with CF expertise; independent audit committee
  • Manager Incentives: 30% compensation tied to PHFSI; multi-year contracts
  • Performance System: Replace process metrics with outcome-based KPIs

🏗️ Long-Term Structural Changes (3-5 years)

Legally Codify Financial Distress:
  • PHFSI < 0.3 = Automatic ministry oversight + restructuring
  • PHFSI 0.3-0.5 = Enhanced monitoring + technical assistance
  • PHFSI > 0.5 = Autonomous operation

Prevents continuous bailout culture; forces proactive management
