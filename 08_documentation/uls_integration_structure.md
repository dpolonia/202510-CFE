# ULS Integration Structure Analysis
## Portuguese National Health Service (SNS) Reorganization

**Date**: 2025-12-31
**Author**: Research Team

---

## Executive Summary

The 2024 ULS integration reform consolidated Portuguese public hospitals into:
- **128 ULS** (Unidades Locais de Saúde)
- **16 IPO** (Institutos Portugueses de Oncologia)
- **Total**: 144 core clinical entities

This represents consolidation of **95 pre-integration hospitals** and **0 ACES primary care groupings**.

## 5. Implications for PHFSI Analysis

### Entity Name Mapping Challenge

**Problem**: Quality metrics from 2017-2023 use pre-integration hospital names (n=95), while post-2024 data uses ULS names (n=128).

**Solution**:
1. Manual mapping of pre-2024 hospitals to parent ULS
2. Create `parent_uls` column in entity crosswalk
3. Aggregate quality metrics by parent ULS for time-series consistency

### CQMI Component Construction

**Current Status**: CQMI (Clinical Quality Maintenance Index) cannot be calculated due to entity name mismatch.

**Required Actions**:
1. **Complete entity crosswalk**: Map 95 hospitals to 39 ULS
2. **Source for mapping**: Use official ACSS decrees or Ministry of Health announcements
3. **Validation**: Verify all hospitals map to exactly one ULS
4. **Aggregate quality data**: Sum/average quality metrics by parent ULS
