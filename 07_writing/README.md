# Writing Directory

This directory contains all manuscript drafts, presentations, and related writing materials.

## Structure

### paper/
Main manuscript files
- `sections/` - Individual paper sections (introduction, theory, methods, etc.)
- `references.bib` - Bibliography file
- `main.tex` or `main.docx` - Main manuscript file

### presentations/
Conference presentations and seminar slides

### drafts/
Earlier versions and draft materials

## Workflow

1. Write individual sections in `sections/` directory
2. Combine sections in main manuscript file
3. Keep presentations separate by venue/date
4. Archive old versions in `drafts/` with date stamps

## Tips

- Use version control (git) for tracking changes
- Reference figures/tables from `06_output/` directory
- Keep bibliography updated in `references.bib`
- Follow journal formatting guidelines from target journal
