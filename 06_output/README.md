# Output Directory

This directory contains all analysis outputs for the research project.

## Structure

### figures/
Publication-quality figures for the paper
- `main/` - Figures for main text
- `appendix/` - Supplementary figures

### tables/
Publication-quality tables
- `main/` - Tables for main text
- `appendix/` - Supplementary tables

### results/
Statistical analysis outputs
- `descriptive/` - Descriptive statistics and data summaries
- `regressions/` - Regression outputs and model results
- `robustness/` - Robustness checks and sensitivity analyses

### data_summaries/
Data documentation and summary reports

## Guidelines

- All outputs should be reproducible from code in `04_code/`
- Use clear, descriptive filenames (e.g., `figure1_phfsi_distribution.pdf`)
- Include figure/table numbers in filenames for easy reference
- Keep source code for each output in corresponding `04_code/05_visualization/` scripts
